# On-device CopyToTranslate Implementation Plan

> Execute inline using the executing-plans workflow. User approved implementation and requested the simplest fully local version, including a button to copy the translation.

**Goal:** Ship a runnable macOS menu bar app that translates newly copied Spanish into English locally.

**Architecture:** Swift package with a small AppKit/SwiftUI executable and a testable clipboard core. On macOS 15 a visible SwiftUI view owns each TranslationSession; setup prepares language downloads and each floating card owns its translation task.

**Tech stack:** Swift 6, AppKit, SwiftUI, NaturalLanguage, Translation, XCTest. No external packages or services.

**Spec:** `docs/functional-description.md`, narrowed by the user's subsequent simple-first instruction.

## Constraints and scope

- macOS 15+, first verified on this Apple silicon Mac running 15.6.
- All detection and translation are local. No OpenRouter code, API keys, telemetry, or clipboard history.
- Preserve clipboard contents until Copy English is explicitly pressed; ignore the app's own clipboard write.
- Fixed top-right card, 10-second dismissal after success, hover pauses dismissal, scrolling for longer translations.
- Menu: pause/resume, translate clipboard manually as Spanish, test translation, setup, quit.
- Setup requires an explicit enable action and prepares Spanish/English downloads through Apple's UI.
- Ignore initial clipboard, uncertain/non-Spanish text, non-text, recognized confidential markers, URLs, email addresses, and selections over 10,000 characters.
- New copies invalidate older work; pause/lock/sleep hide the card and stop monitoring. Resume establishes a fresh baseline.
- Launch-at-login, configurable position/timing, expanded reading windows, and history are deferred.
- This new repository has no commits or existing implementation; work in its dedicated directory on `codex/on-device`.
