The first public release of CopyToTranslate: copy Spanish text and see an English translation without leaving the app you're using.

## Features

- On-device Spanish detection and English translation using Apple's frameworks.
- A quiet, scrollable card at the top right of the screen.
- **Copy English** without replacing your original clipboard automatically.
- A five-second countdown ring that pauses while you hover.
- Emoji-aware detection, manual translation for ambiguous phrases, and menu bar pause/resume.
- Optional launch at login using macOS's native Login Items support.
- A custom app icon and MIT license.

## Download and setup

Download **CopyToTranslate-v0.1.0-macos-arm64.zip**, unzip it, move the app to **Applications**, and open it. Requires an **Apple silicon Mac with macOS 15 or later**. Click **Enable Translation** and approve Apple's Spanish/English language downloads if needed. Translation runs locally once those models are installed.

This build is **ad-hoc signed and not notarized by Apple**. macOS may block the first launch. If you trust the download, follow [Apple's instructions for opening an unidentified developer's app](https://support.apple.com/en-us/102445). A SHA-256 checksum is attached alongside the ZIP.

## Verification and current limits

The release workflow runs the automated tests, builds the app, verifies its signature, and checks the extracted archive before publishing. The translation and clipboard workflow was also manually verified on an Apple silicon Mac running macOS 15.6.

Spanish → English is the only language pair. Intel Macs, cloud translation, clipboard history, and automatic updates are not included. Translation quality depends on Apple's installed models.
