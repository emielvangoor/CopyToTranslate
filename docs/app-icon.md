# App icon

The source artwork is `Resources/AppIcon.png`. It was created with the built-in image generation tool. The build uses macOS `sips` and `iconutil` to produce all standard icon sizes and embeds `AppIcon.icns` in the application. The menu bar retains its monochrome system symbol for readability.

## Generation prompt

Use case: logo-brand. Create one finished macOS application icon for CopyToTranslate, a quiet Spanish-to-English clipboard translation menu-bar utility. 1024x1024 square PNG with a genuinely transparent background outside the icon silhouette, no checkerboard, no mockup. A macOS rounded-square tile centered with generous 8% transparent margin, subtle native dimensional depth and restrained shadow. Within it two overlapping substantial speech/translation cards: the rear card marked with a single crisp Ñ and the front card with a single crisp A, communicating Spanish to English; a small integrated copy-page corner detail if it stays simple. Calm, polished system-app character with a distinctive deep teal tile, warm ivory cards, restrained mint accent. Front-facing orthographic, clean contours, legible at tiny size, minimal shapes, no busy textures. Exactly the two glyphs Ñ and A, no wordmark, no slogan, no flags, no arrows outside the tile, no additional scene or border. Production-ready app icon asset, not an image of an icon sitting on a surface.
