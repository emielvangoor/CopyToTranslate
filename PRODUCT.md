# Product

## Register

product

## Users

An English-speaking Mac user copying Spanish passages while working in other apps.

## Product Purpose

Display an English translation near the screen corner without interrupting the user's work. Detection and translation stay on the Mac. The original clipboard changes only when the user chooses Copy English.

## Brand Personality

Quiet, simple, native. Preserve the existing macOS controls and system appearance.

## Anti-references

Avoid intrusive windows, stacked alerts, decorative animation, and controls that distract from reading or copying the translation.

## Design Principles

- Keep the translation readable and the Copy English action obvious.
- Explain temporary states with subtle, useful feedback.
- Preserve keyboard focus in the user's working app.
- Make automatic dismissal predictable and allow time to read while hovering.

## Accessibility & Inclusion

Follow system appearance, use accessible labels, and respect reduced-motion preferences. No additional individual accessibility requirements have been specified.
